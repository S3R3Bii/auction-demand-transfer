# Auction demand that transfers beyond its training maturities

Protocol and source-access stage. No model has been fitted and no result is claimed. The study will compare announcement-field demand models with maturity-specific historical baselines, separating time transfer from a maturity excluded from fitting. Current historical values make this a retrospective evaluation, not a first-release trading backtest.
